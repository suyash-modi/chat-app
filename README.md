
MOON CHAT - Lunar-Themed Real-Time Messenger 🌙🚀
![MOON CHAT](https://github.com/suyash-modi/chat-app/blob/main/image.png)


🌌 Features

Cosmic Communication
Real-time messaging with socket.io
Dark/light mode with celestial UI themes
Encrypted conversations (E2E coming soon)
Floating message bubbles with lunar animations

Interstellar Interactions
Planetary user status (online/offline)
 avatars with space helmet customization
 

🛰️ Tech Stack

Frontend

React + Vite (Blazing fast launch)
Tailwind CSS (Stellar styling)
Daisy UI (components)

Backend

Node.js + Express (Rocket-powered server)
Socket.IO (Light-speed messaging)
MongoDB (Infinite cosmos database)



🚀 Installation Guide

# Clone the repository
git clone https://github.com/suyash-modi/moon-chat.git 

cd moon-chat

# Install dependencies (both frontend and backend)
npm run setup 

# Configure your .env files
cp client/.env.example client/.env
cp server/.env.example server/.env

# Launch mission control (development)
npm run launch
